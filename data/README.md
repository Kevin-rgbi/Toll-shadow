# Data in this repository

## What is committed here

```
data/catalog/sources.yaml     the source register: 17 sources with SHA-256, authoritative URL,
                              agency, license, coverage, grain, CRS, allowed uses, forbidden claims
data/contracts/*.yaml         ODCS-inspired contracts: traffic observation, MTA daily crossing,
                              release manifest
data/releases/<release_id>/   built release outputs: manifest, quality report, assets, changelog
data/reference-legacy/        legacy Kepler derivatives, kept as reference and used only through validated release assets
```

The browser-facing copy of the current release lives under `public/data/`, generated by the pipeline.
The current pointer is release `2026-09-20.4` and includes traffic observations, facility crossings,
CRZ context, modelled historical air context, historical health context, and archived equity context.
The repository also retains release `2026-09-18.1`, the local AIR/PM2.5 candidate with preliminary
NYCCAS daily and hourly monitor assets.

## What is NOT committed here, and why

The raw source files are **not** in this repository. They total roughly 321 MB, and the two largest
are a 287 MB DOT CSV and a 3.8 MB MTA CSV. Committing them would bloat the repository and duplicate
public open data that anyone can download.

Every raw file is nevertheless fully identified in `data/catalog/sources.yaml`, so it can be obtained
and verified:

| Source ID | Authoritative URL | Raw file | Rows |
|---|---|---|---|
| `dot_automated_traffic_counts_archive_20260915` | https://data.cityofnewyork.us/Transportation/Automated-Traffic-Volume-Counts/7ym2-wayt/about_data | `Automated_Traffic_Volume_Counts_20260915 (1).csv` | 1,875,154 |
| `mta_daily_bridge_tunnel_traffic_archive_20260915` | https://data.ny.gov/Transportation/Daily-Traffic-on-MTA-Bridges-Tunnels/fcbp-umit/about_data | `Daily_Traffic_on_MTA_Bridges_&_Tunnels_20260915.csv` | 98,053 |

Other registered sources (CRZ summary, CBD taxi zones, NYS and NYC disadvantaged communities, NYCCAS
air rasters, NYS asthma, and the legacy Kepler derivatives) are listed with their URLs and statuses
too. The retained 2026-09-18.1 AIR candidate publishes the supplied preliminary NYCCAS PM2.5 daily
and hourly monitor derivatives as checksum-declared browser assets.

## Reproducing the release

1. Download the two approved sources from the URLs above.
2. Place them at the paths the pipeline expects, relative to this repository's parent directory:

```
../data/raw/traffic/Automated_Traffic_Volume_Counts_20260915 (1).csv
../data/raw/traffic/Daily_Traffic_on_MTA_Bridges_&_Tunnels_20260915.csv
```

3. Verify each file against the SHA-256 recorded in `data/catalog/sources.yaml`.
4. Build:

```bash
node pipeline/scripts/build-release.mjs \
   --release-id 2026-09-20.4 \
   --generated-at 2026-09-21T00:46:32.000Z
python3 scripts/release_acceptance.py
```

Using the published release ID and timestamp reproduces the published assets byte for byte. Any other
release ID publishes a new release and repoints `public/data/manifest.json`, which is the intended
release path. A published release is immutable: a correction means a new release ID.

## `data/reference-legacy/`

These seven CSVs are the derivatives that shipped inside the original archive and were used to build
the Kepler project export:

- `Automated_Traffic_Volume_Kepler_Clean_2024_2025.csv` (2,559 rows)
- `MTA_Bridges_Tunnels_Kepler_2024_2025.csv` (8,352 rows)
- `crz_kepler_detection_points.csv` (12 rows)
- `nyc_asthma_kepler.csv` (155 rows)
- `MTA_Central_Business_District_Taxi_Zones_20260911.csv` (38 rows)
- `NYCCAS_PM25_Daily_2025_2026_Kepler.csv` (9,375 rows)
- `NYCCAS_PM25_Hourly_2025_2026_Kepler.csv` (196,861 rows)

**They are not inputs to the published release.** Their transformation recipes were never recorded in
the archive, so the source register marks them `reference_only_pending_reproduction` and the pipeline
does not read them. They are committed here so that a reviewer can compare the published release
against what the archive contained, which is exactly what
`visualization/kepler/validate_kepler_export.py` does by identity, row count, schema, and value.

## Claim boundary attached to this data

- Traffic counts are **samples**. They do not represent continuous or full-year measurement.
- MTA crossings come from a **daily** aggregate view and cannot support hourly analysis.
- A combination the source never observed is **omitted**, never published as zero.
- Historical air-quality and health data are context only, not current local measurement; the separately published preliminary NYCCAS monitor derivatives are labeled as observed concentrations and are not causal estimates.
- Nothing here supports a causal statement about congestion pricing.
